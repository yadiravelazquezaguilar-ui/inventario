# SISTEMA INVENTARIO
Aplicación web de ejemplo que registra y consulta productos

## FUNCIONES PRINCIPALES
- Registrar productos.
- Consultar los productos registrados.
- Mostrar la cantidad disponible.
- Identificar productos sin existencia.
- Consultar la fecha de registro.

## TECNOLOGÍAS
- PHP v.8.2.12
- Mariadb 10.4.32
- HTML
- CSS
- SERVIDOR LOCAL XAMPP (Apache 2.4.58)
- PDO

## INSTALAR
Para ejecutar el sistema se necesita
- XAMPP instalado
- MySQL activado
- Apache activado
- Navegador 
- Herramienta de base de datos

## INSTALACIÓN Y CONFIGURACIÓN
1. Crear una carpeta dentro de C:\xampp\htdocs con el nombre inventario.
2. Copiar el proyecto dentro de la carpeta creada.
3. Importar la base de datos (base_datos.sql).
4. Dentro de la carpeta config, copiar conexion.ejemplo.php como conexion.php y completar tus propios datos de conexión (usuario y contraseña de tu MySQL local).
5. Abrir el navegador y entrar a: http://localhost/inventario/
